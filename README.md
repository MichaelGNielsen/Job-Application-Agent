# Job-Application-Agent

Template til at generere målrettede jobansøgninger og CV'er.

## Kom i gang

1. **Klon projektet:**
   ```bash
   git clone https://github.com/MichaelGNielsen/Job-Application-Agent.git
   ```

2. **Kopier skabelon til .env:**
   ```bash
   cp .env_template .env
   ```

3. **Udfyld dine personlige oplysninger i .env**

4. **Omdøb skabelon-filer** (erstat MINE_INITIALER med dine initialer):
   - `MINE_INITIALER_template_ansøgning.odt` → `mgn_template_ansøgning.odt`
   - `MINE_INITIALER_template_brutto_cv.odt` → `mgn_template_brutto_cv.odt`

5. **Gem jobannoncen** i din ansøgningsmappe:
   - `job.pdf` (gemt fra browser)
   - `job.mhtml` (webarkiv)
   - `job.md` (kopieret tekst)

6. **Læs AGENTS.md** for komplet workflow og dokumentation

## Filer i denne template

| Fil | Beskrivelse |
|-----|-------------|
| `AGENTS.md` | Komplet dokumentation & workflow |
| `.env_template` | Skabelon til personlige indstillinger |
| `job.md` | Vejledning til jobannonse |
| `MINE_INITIALER_template_ansøgning.odt` | ODT skabelon til ansøgninger |
| `MINE_INITIALER_template_brutto_cv.odt` | ODT skabelon til CV |
