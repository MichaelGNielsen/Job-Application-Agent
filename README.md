# Job-Application-Agent

Template til at generere målrettede jobansøgninger og CV'er.

## Kom i gang

1. **Klon projektet:**
   ```bash
   git clone https://github.com/MichaelGNielsen/Job-Application-Agent.git
   ```

2. **Kopier skabelon til .env:**
   ```bash
   cp .env_template .env
   ```

3. **Udfyld dine personlige oplysninger i .env**

4. **Læs AGENTS.md** for komplet workflow og dokumentation

## Filer

| Fil | Beskrivelse |
|-----|-------------|
| `AGENTS.md` | Komplet dokumentation & workflow |
| `.env_template` | Skabelon til personlige indstillinger |
| `mgn_ansøg_template.odt` | ODT skabelon til ansøgninger |
| `mgn_cv_2026_bruto_dk.odt` | Brutto CV (kilde) |

## Hurtig start

Se [AGENTS.md](./AGENTS.md) for detaljeret workflow.
